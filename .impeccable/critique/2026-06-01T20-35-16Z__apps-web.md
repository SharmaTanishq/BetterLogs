## Anti-Patterns Verdict

**LLM assessment:** Not a generic AI landing page, but close on several tells. The workbench demo (CLI snippet + React Flow canvas + two-views comparison) is the strongest differentiator and matches PRODUCT.md's "show the contract" principle. Weak spots: mono uppercase eyebrows on nearly every section, warm peach paper in the cream band, six icon-heading-body cards in Built-for, and em-dash-heavy copy cadence. The page reads as a thoughtful devtool landing with residual SaaS scaffold habits, not a blank template.

**Deterministic scan (CLI):** 1 finding — `em-dash-overuse` in `apps/web/src/app/layout.tsx` metadata (7 em-dashes). Visible page copy also uses em dashes heavily in hero, two-views, how-it-works, and agents sections. Metadata finding is SEO-only; body copy finding is real.

**Visual overlays (browser):** Injection succeeded. Overlays visible in browser tab highlighting:
- `all-caps body text` — section eyebrows and mono labels
- `tiny body text` — 10–11px mono labels throughout panels
- `nested cards` — hero FactTiles, CLI chrome, Built-for benefit rows
- `low contrast text` — void canvas workflow node secondary labels
- `cramped padding` — two-views comparison panels
- `tight line height` — diagnosis card prose
- `overused font: Primary font inter (28% of text)` — informational, not blocking
- `positioned child clipped by overflow container` — workflow canvas drawer on narrow widths

## Overall Impression

BetterLog's landing already proves the product better than most observability marketing pages. The CLI artifact and interactive workflow graph earn trust. The biggest gap before sharing widely is mobile navigation (half the primary IA disappears) and trimming repetitive section scaffolding so the craft matches the positioning.

## What's Working

1. **Workbench demo carries the page.** The hero CLI snippet and `#diagnose` workflow canvas show real product behavior, not decorative chrome. This aligns with Linear/Raycast-style "show the tool" references.
2. **Two-views comparison is sharp positioning.** "30–90 min" vs "Seconds" with span chaos vs case-level diagnosis card makes the moat legible to both engineers and ops.
3. **Waitlist form CLI metaphor.** Terminal-native field row, silent success, verb-first "join" — on-brand and distinct from generic email capture.

## Priority Issues

### [P1] Mobile nav disappears — section IA lost below `md`
- **Why it matters:** Casey and Jordan personas cannot reach Diagnose, Compare, How it works, or Who it's for without scrolling the entire page. Primary navigation becomes a logo + GitHub icon + waitlist CTA.
- **Fix:** Add a compact mobile menu (dialog or popover) with the four anchor links, or expose a horizontal scroll link row. Preserve 44px touch targets.
- **Suggested command:** `/impeccable adapt apps/web/src/components/nav.tsx`

### [P1] Mono uppercase eyebrow on every section
- **Why it matters:** Seven+ sections use the same `font-mono text-[11px] uppercase tracking-[0.12em]` label pattern. This is the exact generic SaaS scaffold listed in PRODUCT.md anti-references.
- **Fix:** Keep one deliberate system label (hero kicker is fine). Remove or vary cadence on subsequent sections — use the split header grid alone, or alternate with inline prose leads.
- **Suggested command:** `/impeccable quieter apps/web`

### [P1] Low contrast on void canvas node labels
- **Why it matters:** Browser detector flagged low-contrast text on workflow nodes. Ops readers and Sam (keyboard/zoom) may miss service names and latency on the signature demo.
- **Fix:** Bump `--color-concrete` opacity on secondary node text; verify ≥4.5:1 for 11–13px mono on `--color-void`.
- **Suggested command:** `/impeccable audit apps/web/src/components/workflow-canvas.tsx`

### [P2] Built-for section is an identical icon-card grid
- **Why it matters:** Six benefits in the same icon + h4 + body template reads as the "identical card grids" absolute ban, even though content differs.
- **Fix:** Collapse to a typographic split list, or lead with one persona quote and fewer rows. Let the two-column persona headers carry hierarchy.
- **Suggested command:** `/impeccable distill apps/web/src/components/agents-section.tsx`

### [P2] Placeholder and broken outbound links
- **Why it matters:** GitHub href is `https://github.com/`; footer SDK/Docs/Changelog/Privacy/Terms are `#`. Alex (engineer champion) hits a dead end; Riley (stress tester) documents trust erosion.
- **Fix:** Wire real URLs or remove links until ready. Never ship `#` in footer columns.
- **Suggested command:** `/impeccable harden apps/web/src/components/footer.tsx`

## Persona Red Flags

**Jordan (First-Timer):** On viewports below `md`, the four section nav links vanish with no alternative. Footer "Docs" goes to `#`. Ops-oriented reader reaching How it works sees a TypeScript block before plain-language payoff.

**Sam (Accessibility-Dependent):** Workflow graph nodes use `role="button"` with `tabIndex={-1}` — not reachable by keyboard despite being the primary interactive demo. Status conveyed partly by dot color; labels exist but focus order skips the canvas entirely.

**Casey (Mobile):** Fixed nav pill sits at top (reachable but not thumb-optimal). No mobile section menu. Workflow drawer stacks below graph on narrow screens; selecting a node requires scrolling to read inspection panel (memory bridge).

**Platform engineer (project-specific):** GitHub icon links to bare github.com root. Hero FactTile "0 Lock-in" reads like a metric strip adjacent to CLI — close to hero-metric template tell.

**Ops on-call (project-specific):** Two-views and diagnosis card are excellent. Built-for and How-it-works lead with SDK jargon blocks before the plain-language outcome ops needs.

## Minor Observations

- Em dash cadence appears in hero body, section descriptions, and metadata — rewrite to commas/colons per voice rules.
- `useInView` + `initial={{ opacity: 0 }}` on section content could ship blank in headless/tab-hidden contexts; hero uses `animate` directly (safer pattern).
- Final CTA headline "Stop reading logs. Start reading workflows." lands aphoristic-cadence; one instance is fine, but it echoes section rebuttal rhythm.
- Agent drawer shows "AI" avatar chip — minor touch on AI-observability anti-reference; consider "BL" or remove badge.
